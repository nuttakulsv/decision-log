# เก็บจำนวนเงินเป็นสตางค์แบบจำนวนเต็ม

## บริบท

ระบบเดิมเก็บราคาเป็น `number` หน่วยบาท ยอดรวมของออเดอร์ที่มีส่วนลดเป็นเปอร์เซ็นต์คลาดไป 1 สตางค์อยู่บ่อย ๆ เพราะ floating point และยอดที่ส่งให้ payment gateway ไม่ตรงกับยอดในใบเสร็จ

## ทางเลือก

| | number หน่วยบาท | Decimal library | integer หน่วยสตางค์ |
|---|---|---|---|
| แรงที่ต้องใช้สร้าง | ไม่ต้องทำอะไร | ต้องแก้ทุกจุดที่คำนวณ | ต้องแก้ทุกจุดที่คำนวณ |
| ความถูกต้อง | ปัดเศษผิดได้ | ถูกต้อง | ถูกต้อง ถ้าปัดตอนคิดส่วนลด |
| เก็บใน PostgreSQL | numeric | numeric | bigint |
| ส่งให้ gateway | ต้องแปลง | ต้องแปลง | gateway รับสตางค์อยู่แล้ว |

## สิ่งที่ตัดสินใจ

เก็บและคำนวณเงินเป็นสตางค์แบบ integer ทั้งระบบ ใช้ type `Satang` ใน `src/shared/money.ts` แปลงเป็นบาทเฉพาะตอนแสดงผล

## ผลที่ตามมา

- ข้อดี: ยอดในใบเสร็จ ฐานข้อมูล และ gateway ตรงกันทุกครั้ง
- ข้อเสีย: โค้ดเก่าต้องย้ายทั้งหมด และคนใหม่ต้องรู้ว่าทุกตัวเลขเงินเป็นสตางค์
- ต้องคอยดู: ถ้าวันหนึ่งต้องรองรับสกุลเงินที่มีทศนิยม 3 ตำแหน่ง
